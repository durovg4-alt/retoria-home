# RETORIA HOME — пакет проекта

Дата фиксации: 26 октября 2026 года.

Этот пакет содержит исходный код, готовую сборку сайта, автономную версию для простого открытия и полную документацию дизайна.

## Быстрый старт

1. Для просмотра без установки откройте папку `READY-TO-OPEN` и дважды нажмите `OPEN-SITE.html`.
2. Для разработки откройте папку `SOURCE`, выполните `npm install`, затем `npm run dev`.
3. Для production-сборки выполните `npm run build`. Результат появится в `dist`.

## Документы

- `01-PROJECT-HANDOFF.md` — назначение, страницы, функциональность, стек и публикация.
- `02-BRANDBOOK.md` — позиционирование, логотип, цвет, шрифты, фотография и tone of voice.
- `03-DESIGN-SYSTEM.md` — сетка, отступы, радиусы, типографические и компонентные правила.
- `04-MOTION-SPEC.md` — все анимации и параметры движения.
- `05-ASSET-INVENTORY.md` — перечень визуальных материалов и размеры.
- `06-SKILLS-AND-TOOLS.md` — использованные подходы, скиллы, библиотеки и инструменты.
- `07-QA-CHECKLIST.md` — чек-лист проверки дизайна и разработки.

## Важный статус

Это интерактивный front-end прототип. Корзина, избранное, фильтры, сравнение изображений, формы и переходы работают в браузере. Реальная оплата, отправка заказов, CRM, серверное хранение и AI-генерация пока не подключены.
