# RETORIA HOME — QA checklist

## Visual

- [ ] Большой заголовок hero не обрезается шапкой на desktop и mobile.
- [ ] Карточки и тексты выровнены по общей сетке.
- [ ] Радиусы фотографий единообразны.
- [ ] Нет случайных квадратных изображений среди rounded feature blocks.
- [ ] Нижние блоки сохраняют достаточную высоту и не выглядят сплюснутыми.
- [ ] Контент не перегружен текстом и конкурирующими CTA.
- [ ] Все иконки в header одинаковы на всех страницах.

## Navigation and flows

- [ ] Каталог, коллекции, комнаты, доставка, контакты открываются.
- [ ] Сердце ведёт в избранное, а не в отзывы.
- [ ] Избранное сохраняется после перезагрузки.
- [ ] Добавление в корзину обновляет badge.
- [ ] Quantity и удаление корректно пересчитывают итог.
- [ ] Доставка → оплата → подтверждение проходят без тупика.

## Catalog and product

- [ ] Filter header, reset, count и sort выровнены.
- [ ] Фильтрация категорий изменяет количество видимых товаров.
- [ ] Все product images загружаются и имеют одинаковое соотношение сторон.
- [ ] Thumbnail gallery работает.
- [ ] Размер, цвет и количество имеют явное selected state.
- [ ] Раздел AI расположен после характеристик.
- [ ] Отзывы и «Вам может понравиться» доступны ниже товара.

## AI try-on

- [ ] Верхнее поле загрузки невысокое и широкое.
- [ ] Загруженное фото появляется в comparison.
- [ ] Большой нижний before/after slider двигается мышью и касанием.
- [ ] Выбор штор меняет after image.
- [ ] Есть пояснение, что в прототипе AI-генерация демонстрационная.

## Responsive

- [ ] Проверено на ширинах 1440, 1280, 1024, 768, 390 и 320 px.
- [ ] На mobile нет горизонтального overflow страницы.
- [ ] Горизонтальный showcase имеет scroll snap и видимые controls.
- [ ] Формы переходят в одну колонку.
- [ ] Touch targets не меньше примерно 44 × 44 px.

## Accessibility

- [ ] Весь сценарий доступен с клавиатуры.
- [ ] Focus outline виден.
- [ ] Inputs имеют labels.
- [ ] Icon buttons имеют aria-label.
- [ ] Контраст проверен по WCAG AA.
- [ ] При reduced motion нет scroll pin, parallax или forced smooth scroll.

## Performance

- [ ] Production build завершается без ошибок.
- [ ] Нет 404 для JS, CSS, fonts и images.
- [ ] Hero загружается при первом экране без заметного layout shift.
- [ ] Ни один product image не превышает разумный размер после оптимизации.
- [ ] Lighthouse проверен отдельно для mobile и desktop.

## Перед коммерческим запуском

- [ ] Заменены тестовые телефон, email, адрес и номер заказа.
- [ ] Подключены реальные политика конфиденциальности и оферта.
- [ ] Получено согласие на обработку загружаемых фотографий.
- [ ] Подключены backend, CMS/остатки, CRM, доставка и платёжный провайдер.
- [ ] Проверены права на название, фотографии, шрифты и контент.
