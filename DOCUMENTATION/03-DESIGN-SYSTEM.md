# RETORIA HOME — дизайн-система

## 1. Layout

- Максимальная ширина основного контейнера: `1440 px`.
- Основной `.shell`: `100% - clamp(32px, 6vw, 112px)`.
- Контейнер главной `.home-shell`: `min(92.4%, 1420px)`.
- Desktop-композиция построена на 12-колоночной логике с визуальным gutter около `18–24 px`.
- Вертикальный ритм больших разделов: `88–152 px`.
- Компактные коммерческие разделы: `64–104 px`.

## 2. Breakpoints

| Breakpoint | Поведение |
|---|---|
| `≤1080 px` | Упрощение внутренних сеток и карточек |
| `≤900 px` | Главный горизонтальный showcase становится touch-слайдером; hero и footer перестраиваются |
| `≤780 px` | Мобильная навигация, одноколоночные формы и product layout |
| `≤600 px` | Компактная главная, уменьшенные радиусы и отступы |
| `≤460 px` | Самые узкие экраны, сокращённые controls и типографика |

## 3. Типографическая шкала

- Hero wordmark: `clamp(115px, 13.1vw, 191px)`, line-height `.76`.
- Основной display: `clamp(44px, 5.8vw, 88px)`, line-height `.98`.
- Small display: `clamp(34px, 4.1vw, 58px)`.
- Заголовок карточки: примерно `20–28 px`.
- Основной UI: `13–15 px`.
- Eyebrow: `11 px`, uppercase, letter-spacing `.15em`.

## 4. Spacing

Базовая практическая шкала: `4, 8, 12, 16, 18, 24, 32, 40, 52, 64, 80, 104, 152 px`.

- Между заголовком и текстом: `20–28 px`.
- Между секциями: не менее `64 px` на мобильном и `88 px` на desktop.
- Внутри карточек: `12–24 px`.
- В feature-блоках: `30–74 px`.

## 5. Компоненты

### Header

- Desktop: logo по центру, navigation слева/по центру, utility icons справа.
- На внутренних страницах sticky с blur `18 px`.
- Все иконки имеют единый outline-стиль.

### Buttons

- Primary: moss background, белый текст, высота от `50–52 px`.
- Secondary: прозрачный фон, тонкая граница.
- Pill используется для компактных действий, но не для больших контентных контейнеров.
- Hover: лёгкий подъём, затемнение фона или сдвиг стрелки.

### Product card

- Вертикальная фотография `4:5`.
- Сверху — badge и heart; снизу — quick add.
- Под фото: название, оттенок, цена и AI-ссылка только для штор.

### Feature card

- Крупное изображение и один смысловой тезис.
- Радиус `28–34 px`.
- Не дублировать композицию карточек интерьерной подборки.

### Forms

- Понятные labels над полями.
- Сетка 2 колонки на desktop и 1 колонка на мобильном.
- Дата и время доставки всегда выровнены в одной строке и имеют одинаковую высоту.
- Ошибки должны появляться рядом с конкретным полем.

### AI comparison

- Полноразмерная область с двумя изображениями.
- Range input растянут поверх всего блока.
- Вертикальный divider и круглый handle показывают текущее разделение.
- Подписи «До» и «После» закреплены по верхним углам.

## 6. Состояния

- Hover: мягкий scale изображения до `1.025–1.035`.
- Focus: outline `2 px` Moss с offset `4 px`.
- Selected: Moss background или Moss border.
- Disabled: требуется opacity и отсутствие pointer action при production-реализации.
- Empty favorites: иконка, короткий текст и один CTA.
- Toast: короткое подтверждение добавления, сохранения или demo-submit.

## 7. Accessibility

- Есть skip-link к основному содержанию.
- Интерактивные иконки имеют `aria-label`.
- Избранное использует `aria-pressed`.
- Основные изображения имеют alt-текст.
- Поддерживается `prefers-reduced-motion`.
- Не полагаться только на цвет при сообщении статуса.
- Для production увеличить мелкие тексты 9–11 px там, где они несут критически важную информацию.
