# RETORIA HOME — полный handoff проекта

## 1. О проекте

RETORIA HOME — прототип премиального интернет-магазина домашнего текстиля. Главная идея интерфейса: «тихая роскошь», натуральные материалы, большое количество воздуха, спокойная редакционная композиция и минимальный объём текста.

Главный продуктовый дифференциатор — AI-примерка штор в интерьере пользователя.

## 2. Цель и аудитория

Цель: провести пользователя от знакомства с брендом до выбора текстиля, визуальной примерки, добавления в корзину и оформления заказа без ощущения перегруженного маркетплейса.

Основная аудитория: покупатели домашнего текстиля, которым важны эстетика, фактура, спокойные природные оттенки и уверенность в том, как изделие будет выглядеть дома.

## 3. Страницы и маршруты

Проект использует hash-маршрутизацию, поэтому работает на статическом хостинге.

| Страница | Маршрут | Назначение |
|---|---|---|
| Главная | `#/home` | Бренд, категории, интерьерные подборки, преимущества, AI-примерка |
| Каталог | `#/catalog` | Фильтры, сортировка, карточки товаров, избранное и быстрое добавление |
| Карточка товара | `#/product` | Галерея, цвет, размер, количество, характеристики, AI, отзывы |
| AI-примерка | `#/ai` | Загрузка фото, выбор штор, интерактивное сравнение до/после |
| Отзывы | `#/reviews` | Рейтинг, фильтр по оценке и отзывы покупателей |
| Избранное | `#/favorites` | Сохранённые товары |
| Корзина | `#/cart` | Состав заказа, количество, удаление, допродажа |
| Доставка | `#/delivery` | Контакты, адрес, дата, время и комментарий |
| Оплата | `#/payment` | Способ оплаты и демонстрационная форма карты |
| Подтверждение | `#/confirmation` | Номер заказа, доставка и состав заказа |
| О бренде / контакты | `#/contacts` | История, шоурум, контакты и форма обращения |

## 4. Основные пользовательские сценарии

1. Главная → каталог → товар → выбор размера/цвета → корзина → доставка → оплата → подтверждение.
2. Главная или товар → AI-примерка → загрузка фото → выбор модели → сравнение до/после.
3. Каталог → добавление в избранное → страница избранного → товар или корзина.
4. Карточка товара → отзывы → фильтрация отзывов по оценке.

## 5. Реализованная интерактивность

- Адаптивная навигация и мобильное меню.
- Фильтрация каталога по категории и сброс фильтров.
- Выбор размера, цвета и количества товара.
- Галерея миниатюр в карточке товара.
- Добавление и удаление товаров из корзины.
- Избранное с сохранением между перезагрузками.
- Корзина с сохранением между перезагрузками.
- Интерактивный before/after-слайдер.
- Загрузка локальной фотографии пользователя для preview.
- Выбор модели штор для визуального сравнения.
- Валидация обязательных полей доставки.
- Демонстрационные формы и toast-уведомления.
- Переходы между всеми этапами оформления.

Данные корзины хранятся в `localStorage` под ключом `retoria-cart`, избранное — `retoria-favorites`.

## 6. Что является демонстрацией

- Оплата не отправляет банковские данные и не подключена к платёжному провайдеру.
- AI-примерка показывает заранее подготовленное сравнение и локальный preview; внешняя AI-модель не подключена.
- Формы не отправляются на сервер или в CRM.
- Товары и отзывы заданы в `src/main.js`.
- Контакты, номер заказа, адрес и данные получателя являются примерными и должны быть заменены перед production.

## 7. Технологический стек

- Vite 7 — сборка и dev-сервер.
- Vanilla JavaScript ES modules — интерфейс, маршруты и состояние.
- CSS без UI-фреймворка — дизайн-система и адаптивность.
- GSAP 3 + ScrollTrigger — анимации и скролл-хореография.
- Lenis — плавный скролл.
- Fontsource — локальная поставка шрифтов без Google Fonts.
- WebP — основные изображения.

## 9. Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно `http://localhost:5173`.

Production-проверка:

```bash
npm run build
npm run preview
```

Создание автономной версии:

```bash
npm run portable
```

## 10. Публикация

### Vercel

Проект настроен файлом `vercel.json`. После импорта репозитория или выполнения `vercel --prod` Vercel запускает `npm run build` и публикует папку `dist`.

### GitHub Pages

Сайт совместим со статическим размещением благодаря `base: "./"` и hash-маршрутам. На Pages публикуется содержимое `dist` в ветку `gh-pages`.

### Любой статический хостинг

Выполните `npm run build` и загрузите содержимое папки `dist` в корень сайта.

## 11. Production-план

Перед запуском настоящего магазина нужно:

1. Подключить каталог/остатки, CMS или InSales API.
2. Подключить серверную корзину, заказы и авторизацию.
3. Подключить платёжного провайдера и не обрабатывать данные карты самостоятельно.
4. Подключить службу доставки и расчёт стоимости/слотов.
5. Реализовать AI-пайплайн: загрузка, согласие пользователя, обработка, хранение и удаление изображений.
6. Заменить тестовые контакты, юридические документы и реквизиты.
7. Добавить аналитику, события конверсии, SEO metadata, sitemap и robots.txt.
8. Провести нагрузочное, кроссбраузерное и accessibility-тестирование.
